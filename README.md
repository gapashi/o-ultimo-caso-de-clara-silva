## 🔎 Sobre o projeto

*O Último Caso de Clara Silva* é uma aventura de investigação no estilo point and click com elementos de visual novel, criada como demo para uma festa de Halloween.

Explore cenários, interaja com objetos e personagens, e descubra o que aconteceu no último caso de Clara Silva.

## 🛠️ Tecnologias

- [Unity](https://unity.com/) (2D)
- C#
